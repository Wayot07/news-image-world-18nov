A broadsheet front-page image summing up the world's news of Wednesday 18 November 2026: U.S. jets strike an Iranian missile site on Qeshm Island and Iran fires drones at Bahrain and Kuwait, Ukraine hits the Kerch Bridge a second day, Xi, Putin and Trump are set for a first trilateral summit in Shenzhen, Peltola wins Alaska's Senate seat, the U.S. loses measles-free status, Ebola surges in Congo, cold kills in Gaza's tents, a Russian An-12 crashes in Siberia, and earthquakes and Cyclone Xavier strike. The program copies entry.png to /output/entry.png.

Built for the make.fun bounty of the same name.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
